# Alexandria

Original, unmodified Alexandria variable font from the official Google Fonts repository. The font binary is also identical to the original project repository's current variable font. Both repositories provide the variable TTF; no WOFF2 is included in their published font directories.

- Font: `Alexandria-Variable.ttf` (332,488 bytes; original filename `Alexandria[wght].ttf`).
- Family: `Alexandria`; normal style.
- Weight axis: continuous `wght` 100–900, default 400.
- Named weights: Thin 100, ExtraLight 200, Light 300, Regular 400, Medium 500, SemiBold 600, Bold 700, ExtraBold 800, Black 900.
- Designers: Mohamed Gaber and Julieta Ulanovsky.
- Coverage: Arabic, Latin, Latin Extended, and Vietnamese according to Google Fonts metadata. The binary contains 1,935 glyphs, including 101 encoded characters in the Arabic Unicode block. Arabic initial, medial, final, and required-ligature shaping features are present. Arabic letters and digits in “ديستريكت إلفيرا الإسكندرية اختبر الخط العربي ١٢٣٤٥٦٧٨٩٠” were verified against the character map.
